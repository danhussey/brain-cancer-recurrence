# Product Sense

The product is a retrospective glioma recurrence-risk research harness. Its value is in making a difficult imaging workflow reproducible enough to compare hypotheses.

## Primary Users

- Imaging researchers building recurrence-risk models.
- Radiation oncology collaborators reviewing derived maps and masks.
- ML engineers validating model baselines and evaluation protocols.

## Success Criteria

- A new site can understand the manifest and derived-file contracts from repo docs alone.
- Every prediction has a corresponding QC report.
- Evaluation currently compares the voxel-logistic MRI model against the simple tumor-distance baseline.
- The repository refuses clinical-use framing until prospective validation and regulatory controls exist.
