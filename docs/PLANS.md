# Plans

Plans are versioned repository artifacts. Small changes can use short in-turn plans, but multi-step implementation work should create an execution plan under `docs/exec-plans/active/` and move it to `docs/exec-plans/completed/` when finished.

## Index

- Active plans: `docs/exec-plans/active/`
- Completed plans: `docs/exec-plans/completed/`
- Technical debt tracker: `docs/exec-plans/tech-debt-tracker.md`

## Plan Rules

- Plans should include goal, work items, decisions, and verification.
- Completed plans should record concrete test results.
- Do not rely on chat history for durable project decisions.
